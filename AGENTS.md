# Agent instructions

Before changing the daily brief (clustering, tags, titles, industry cards, card CSS, or `npm run run-daily`), follow [docs/OWNER-QUALITY-RULES.md](docs/OWNER-QUALITY-RULES.md). Owner 歪歪 set these rules on 2026-10-12. They are mandatory. Do not weaken them.

1. Cluster by event, not channel. Extra sources only in the detail.
2. 当天重要摘要: new-car events first. Tag `新车` only for a specific model's launch, unveil, 上市, 官宣, 谍照, or 申报 — not user portraits, sales, policy, OTA, or partnerships.
3. A story that is not a single brand goes to 行业信息, not 其他品牌.
4. Titles name a concrete subject and event. Drop 导语, `IT早报` greetings, and empty 「从相关渠道获悉」.
5. Industry signal cards: source text and summary must not overlap. The same report is one card.
6. Do not redesign card layout or CSS except to fix a bug.
7. The daily run must not depend on paid OpenAI.
8. 新车一览 auto-updates from qualifying 新车 events (上市 / 官宣 / 亮相 / 谍照 / 申报). Same strict 新车 definition. Do not invent prices or launch days.
